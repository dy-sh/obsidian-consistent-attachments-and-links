# Source note

This note exists to demonstrate the link-rewriting commands. It links to [Shared target](<../../Materials/04 Reorganize and convert links/Shared target.md>) - a note sitting right beside it, reached by a path that climbs all the way out to the vault root and walks back down. It resolves, but it breaks the moment either folder is renamed, and it tells a reader nothing about where the target actually is.

Follow the steps in [04 Reorganize and convert links](<../../04 Reorganize and convert links.md>): run **Convert All Link Paths to Relative** and watch that path collapse to `Shared target.md`, the shortest path that resolves from this note wherever you open it - while the wikilink inside [Diagram.excalidraw](<./Diagram.excalidraw.md>) is deliberately left alone.
